# Softify v2.0.6 Stable Release Notes

## 📌 Release Overview
Softify **v2.0.6 Stable** is a landmark release introducing major audio fidelity enhancements, a streamlined dark mobile UI overhaul, smart multi-artist navigation, auto-dubbing audio filtering for web streams, local music indexing, on-device karaoke romanization, and the interactive Softify Wrapped engine.

All features strictly honor Softify’s architectural pillars: **100% client-side, zero accounts, zero telemetry, local-first SQLite persistence, and uncompressed studio master audio**.

## 🚀 Features & Enhancements by Category

### 1. 🧑‍🎤 Multi-Artist Navigation & Discovery Engine
* **Multiple Artists Chooser Sheet**: When playing or viewing tracks with multiple collaborating artists (separated by `,`, `&`, `feat.`, `ft.`, `with`, `/`, `;`), clicking "View artist" or tapping the artist on the player opens a clean dark modal bottom sheet displaying each artist with their avatar, name, and profile link.
* **Direct 1-Artist Fast Path**: Tracks with a single artist bypass the dialog and navigate straight to the artist's discography.
* **Smart Artist Radio Anchoring**: Artist radio queries now isolate the primary artist from collaborative strings, ensuring valid 25-song queues without search failures.
* **Deep-Dive Discography Navigation**: 1-tap "Discography" button on Artist Detail pages with instant switching between Albums, Singles, and Top Releases.

### 2. 🎧 Core Audio & Streaming Architecture
* **Original Audio Stream Preservation**: Resolved multi-language auto-dubbing issues on direct video link playback. The stream resolver now detects and filters out auto-dubbed foreign language tracks (`isAutoDubbed: true`, `acont=dubbed-auto`) and strictly prioritizes the creator's authentic original audio stream (`acont=original:lang=en-US`).
* **320kbps Ultra HD Studio Master Preset**: Direct decoding of uncompressed 320kbps AAC studio masters (`AudioQualityPreset.high`) with zero movie dialogue or promo voiceovers.
* **10-Band Hardware DSP Equalizer**: Integrated native Android `AudioEffect` and Linux PipeWire/PulseAudio sink filtering. Features 6 acoustic presets (Bass Boost, Vocal Clarity, Electronic, Rock, Acoustic, Flat) and custom parametric sliders from 31Hz to 16kHz.
* **Full-Width Desktop EQ Console**: Redesigned desktop layout with responsive `Expanded` bands so all 10 frequency channels are visible side-by-side with zero horizontal mouse clipping.
* **DJ Audio Crossfade Engine**: Smooth dual-engine volume interpolation between active and preloaded tracks (0s to 12s configurable slider in Settings).
* **Loudness Normalization (ReplayGain / EBU R128)**: Equalizes perceived loudness across diverse studio sources to prevent volume jumps between quiet acoustic and loud modern recordings.
* **Dual Buffer-Ahead Track Progress**: Real-time scrubber visualizes active playback position alongside pre-buffered stream progress with tactile haptic feedback.

### 3. 📱 Mobile & Desktop UI Polish
* **Compact Quick-Access Bento Grid**: Compacted "Liked Songs" and "Downloads" into a 52px-height row with 8px rounded corners on `#282828` background, elevating "Made For You" and "Recently Played" shelves to the top.
* **Refined Navigation Icons**: Updated Library navigation icon to the clean collections bookmark symbol (`Icons.collections_bookmark_outlined`) and official video link icon.
* **De-Cluttered Navigation Bar**: Streamlined navigation down to Home, Search, Paste Link, and Library for zero visual noise.
* **Linux Mobile Viewport Mode**: Added `--mobile` command-line switch and `SOFTIFY_MOBILE=1` environment flag for testing true 412×860 phone viewports on desktop Linux.
* **Kinetic Waveform Indicator**: 60fps custom-painted animated equalizer wave indicator rendered across Mini-Player, Queue Bottom Sheet, and Track Rows while music is playing.
* **Audiophile Micro-Pill & Telemetry Inspector**: Live badge in MiniPlayer displaying active codec/bitrate (320 KBPS, FLAC, AAC) with a 1-tap modal inspecting buffer health and DAC pipelines.

### 4. 📜 Synced Karaoke Lyrics & Indic Romanization
* **On-Device ScriptRomanizer**: Zero-network, deterministic transliterator converting Devanagari (Hindi, Marathi, Nepali, Sanskrit) and Gurmukhi (Punjabi) lyrics into Latin phonetics in real-time.
* **Instant `[ROM]` / `[ORIG]` Toggle**: One-tap switch in lyrics header allowing seamless sing-along without external API latency.
* **Interactive Font Sizing Controller**: Dynamic font scaling (Compact 17px, Normal 21px, Large 26px) with preference persisted in local Drift SQLite.
* **High-Coverage Global Lyrics Database**: Native integration with verified lyrics databases covering Indian and international music catalogs.
* **Multi-Source Lyrics Fallback Cascade**: Automatic failover across multi-tiered verified and community lyrics providers (including LRCLIB) with zero rate limits.
* **Shareable Lyric Quote Cards**: Long-press any lyric line to generate and copy a styled quote snippet with track and artist attribution.

### 5. 📁 Local Device Audio & Storage Management
* **Device Storage Scanner**: Scans and indexes local files (`.mp3`, `.m4a`, `.flac`, `.wav`, `.ogg`) into local SQLite with album artwork extraction.
* **Offline Storage Doctor**: 1-tap "Verify & Repair Offline Library" scans filesystem, removes stale database rows, cleans orphaned cache files, and re-syncs physical file sizes.
* **Multi-Sort Library Header**: Sort Liked Songs, Downloads, and Local Music by `Recent`, `Title A-Z`, or `Artist A-Z` with instant batch "Play All" and "Shuffle".
* **1-Tap Folder Launcher**: Opens the physical storage directory natively via `xdg-open` (Linux), `open` (macOS), `explorer.exe` (Windows), or Android Documents Provider.
* **Proportional Cache Breakdown**: Live multi-color visualizer in Settings distinguishing Offline Downloads, Audio Cache Buffer, and Synced Lyrics data.
* **1-Click Encrypted Backup & Restore**: Export and import playlists, favorites, listening history, and preferences to a single `.softify` archive.

### 6. 📊 On-Device Insights ("Softify Wrapped") & Smart Playlists
* **Interactive Wrapped Dashboard**:
  * **Listening Archetypes**: Automatic categorization (*Night Explorer*, *Sonic Voyager*, *Deep Diver*, *Morning Energizer*, etc.).
  * **Multi-Period Filters**: Filter insights across *All Time*, *Past 30 Days*, and *Past 7 Days*.
  * **24-Hour Rhythm & Clock**: 24-column hourly activity bar chart and day-quadrant breakdown.
  * **Ranked Top Tracks & Artists**: Top 5 songs with 1-tap play and top 5 artists with duration and listening share percentages.
  * **Shareable Card**: AMOLED poster-style Wrapped card with 1-click clipboard summary export.
* **Dynamic Smart Playlists**: Auto-updating collections generated from listening history (*On Repeat*, *Most Played This Month*, *Forgotten Favorites*).

### 7. ⏱️ Playback Control & System Integrations
* **Precision Sleep Timer Engine**: Quick presets (5m to 1h), custom duration (up to 24h), and "End of this song" mode governed directly by foreground media services.
* **Android Material You Widgets**: 4×1 compact pill and 4×2 expansive card home-screen widgets with dynamic system colors and playback controls.
* **Discord Rich Presence (Linux/Desktop)**: Broadcasts "Listening to [Song] on Softify" with live timestamps via local Unix IPC socket (zero third-party API tokens).
* **Landscape Car Mode**: High-contrast, large-button driving interface optimized for dashboard mounts and automotive head units.

## 🐛 Bug Fixes & Stability Ledger

| Issue | Root Cause | Resolution |
| :--- | :--- | :--- |
| **Video Audio Mismatch** | Multi-language auto-dubbed streams (`acont=dubbed-auto:lang=ko`) selected over creator audio. | Filtered out dubbed streams; strictly prioritize original audio (`acont=original:lang=en-US`). |
| **Cross-Artist Track Leaks** | Loose substring matching caused tracks to appear on unrelated artist profiles. | Enforced strict artist ID matching and diacritic-normalized catalog queries via `TextNormalizer`. |
| **Synthetic Album Injections** | Web stream fallbacks injected fabricated album names into track metadata. | Strip synthetic album tags from video streams; keep album field `null` unless verified. |
| **Linux Window Identity** | Softify window launched under generic "Settings" class on GNOME/X11 desktops. | Enforced `com.softify.softify` application ID in `my_application.cc`, matching `.desktop` `StartupWMClass`. |
| **Equalizer Clipping on Desktop** | Fixed 58px band layout clipped bands 9 (8kHz) and 10 (16kHz) on desktop Linux. | Implemented responsive `LayoutBuilder` / `Row` of `Expanded` bands so all 10 bands fit visible on screen. |
| **Local Music Crawl Pollution** | Recursive scanner indexed build artifacts (`node_modules`), UI sounds, and short audio clips. | Added 300 KB size cutoff, folder blacklists, `.nomedia` compliance, and automatic orphan pruning on rescan. |
| **Dangling Sleep Timers** | Background timer tickers occasionally persisted after task teardown. | Added explicit cancellation hooks to `onTaskRemoved()`, `stop()`, and `dispose()` lifecycles. |
| **Wrapped Telemetry Inflation** | Zero-duration skips and podcasts artificially skewed listening hours and top artists. | Filtered podcasts and early skips (<15s) from telemetry; anchored stats in high-precision `play_events`. |
| **Missing Equalizer Back Button** | Equalizer view occasionally lacked a leading back arrow depending on navigation stack. | Unconditionally rendered leading back button falling back safely to root navigator popping. |
