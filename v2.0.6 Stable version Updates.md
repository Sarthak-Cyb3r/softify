# Softify v2.0.6 Stable Version Updates

## 📌 Release Summary
Softify **v2.0.6 Stable** brings essential audio fidelity tools, local music playback, ecosystem expansions, smart discovery playlists, interactive on-device Wrapped insights, and critical catalog deduplication bug fixes while preserving Softify's core promise: **100% client-side, zero accounts, zero telemetry, and pure studio master audio**.

---

## 🚀 Features & Enhancements

### 1. ⏱️ Sleep Timer Engine [DONE]
- **Presets & End-of-Song Mode**: Quick presets (5m, 10m, 15m, 30m, 45m, 1h), "End of this song", and custom duration dialog (1–1440 minutes).
- **Background-Safe Precision**: Governed directly by `SoftifyAudioHandler` via foreground media services so timers stay active even when the screen is locked.
- **Queue Protection**: Halts playback cleanly and prevents automatic next-track queue advancement once the timer expires.
- **Persistent Access**: Accessible via 3-dots menus on mobile, mini-player, full-screen player, and desktop player bar.

### 2. 🎛️ 10-Band Equalizer & Bass Boost [DONE]
- **Native Hardware DSP**: Android `AudioEffect` integration and Linux PipeWire/PulseAudio sink filtering.
- **Acoustic Presets**: Bass Boost, Vocal Clarity, Electronic, Rock, Acoustic, and Flat.
- **Custom Parametric Control**: 10-band frequency adjustment (31Hz–16kHz) with fine gain stepping (-12dB to +12dB).
- **Responsive Desktop Console**: Full-width console layout ensuring all 10 bands (`31Hz` through `16kHz`) are visible simultaneously side-by-side with zero horizontal mouse-scroll clipping.

### 3. 🔊 Loudness Normalization (ReplayGain / EBU R128) [DONE]
- Uniform perceived loudness leveling across varying studio sources, eliminating volume spikes between quiet acoustic recordings and loud master tracks.

### 4. 📁 Local Device Music & Offline File Player [DONE]
- **Storage Scanner**: Scans device storage for local audio tracks (`.mp3`, `.m4a`, `.flac`, `.wav`, `.ogg`) and indexes metadata into local Drift SQLite.
- **Unified Library**: Seamlessly blends local files, downloaded tracks, and streamed songs into custom playlists and search results.
- **Device Music Tab**: Dedicated tab in Library screen with real-time rescan and direct track playback.

### 5. 📱 OS & Ecosystem Integration [DONE]
- **Android Material You Widgets**: 4×1 compact pill and 4×2 expansive card home-screen widgets with dynamic system colors, album art, and playback controls.
- **Desktop Discord Rich Presence**: Broadcasts "Listening to [Song] on Softify" with live timestamps via local Unix IPC socket (zero third-party developer tokens).
- **Android Auto & Landscape Car Mode**: High-contrast, large-button driving interface optimized for automotive head units and car mounts.

### 6. 📻 Smart Playlists & Personal Insights ("Softify Wrapped") [DONE]
- **Track & Artist Radio**: 1-tap "Start Radio" in track 3-dots menus generating a 25-song queue musically anchored via the on-device PPMI co-occurrence graph.
- **Dynamic Smart Playlists**: Auto-updating collections generated from listening history (*On Repeat*, *Most Played This Month*, *Forgotten Favorites*).
- **Interactive Wrapped & Insights Dashboard**:
  - **Multi-Period Filters**: Toggle between *All Time*, *Past 30 Days*, and *Past 7 Days*.
  - **Listening Archetypes**: Automatic persona categorization (*Night Explorer*, *Sonic Voyager*, *Deep Diver*, *Morning Energizer*, *Afternoon Flow*, *Evening Chill*).
  - **Bento Metrics**: Total hours, tracks streamed, artists discovered, and track completion rate.
  - **Ranked Top Tracks & Artists**: Top 5 songs with cover art and 1-tap play; top 5 artists with duration and listening share percentages.
  - **24-Hour Rhythm & Clock**: Visual 24-column hourly activity bar chart and day quadrant breakdown.
  - **Shareable Wrapped Card**: AMOLED poster-style Wrapped card with 1-click clipboard summary exporter.
  - **Desktop Sidebar Access**: Dedicated quick-launch item in Desktop Sidebar under *Features*.

### 7. 💾 1-Click Library Backup & Restore [DONE]
- Portable export and import of playlists, liked tracks, listening history, and user settings into an encrypted `.softify` backup archive.

### 8. 📂 1-Tap Saved Songs Folder Opener [DONE]
- **Cross-Platform Storage Access**: Direct 1-tap folder opening from the Downloads storage bar, empty state, and Settings Storage & Cache section.
- **Native OS Handlers**: Launches system file managers natively via `xdg-open` on Linux, `open` on macOS, `explorer.exe` on Windows, and Android FileProvider/Documents intent with clipboard fallback on mobile.

### 9. 🎚️ DJ Audio Crossfade Engine [DONE]

## 🐛 Bug Fixes & Stability Improvements

### 1. 🧑‍🎤 Fix Cross-Artist Track Leaks [DONE]
- **Issue**: Songs from different artists with similar names or compilation contributions occasionally appeared under unrelated artist profiles.
- **Fix**: Stricter artist ID validation, exact-match filtering in catalog queries, and diacritic-normalized substring matching via `TextNormalizer.matchesArtist`.

### 2. 🎬 Remove Artist Album from YouTube Videos [DONE]
- **Issue**: YouTube music and video stream fallbacks frequently injected artificial, inaccurate album names into track metadata.
- **Fix**: Strip synthetic album tags from YouTube video streams; keep album field empty (`null`) unless verified by official catalog APIs.

### 3. 🐧 Linux Window Class & Launcher Identification [DONE]
- **Issue**: Softify window opened under the generic "Settings" window class on GNOME/X11 desktops instead of its proper app identity.
- **Fix**: Enforced `com.softify.softify` application ID in `my_application.cc`, matching `.desktop` `StartupWMClass`.

### 4. 🧹 Background Timer Lifecycle Hardening [DONE]
- **Issue**: Dangling timer tickers could persist after test teardown or background task termination.
- **Fix**: Integrated explicit cancellation hooks into `onTaskRemoved()`, `stop()`, and `dispose()` lifecycles.

### 5. 🎚️ 10 Equalizer Bands Visibility on Desktop Linux [DONE]
- **Issue**: In desktop window layouts, fixed 58px bands inside a horizontal scroll view clipped bands 9 (8kHz) and 10 (16kHz), requiring non-standard horizontal trackpad scrolling.
- **Fix**: Redesigned desktop layout with a responsive `LayoutBuilder` / `Row` of `Expanded` bands spanning the full width so all 10 bands are visible and adjustable at once.

### 6. 📊 Softify Wrapped Accuracy & Desktop Modal Presentation [DONE]
- **Issue**: Zero-duration skipped tracks and podcasts artificially inflated listening hours and top artist rankings; mobile bottom sheet stretched awkwardly across desktop displays.
- **Fix**: Filtered out podcasts and early skips from music telemetry, prioritized high-precision `play_events` data, and transitioned to a centered desktop modal with close controls.

### 7. 🎵 Local Music Finding Quality, Pruning & Playback Isolation [DONE]
- **Issue**: Unrestricted recursive directory crawls indexed non-music development files (e.g. `node_modules`, UI sound FX, short beeps <300KB) and kept stale/deleted files in SQLite; tapping missing or short files fell back to online streaming or failed.
- **Fix**:
  - Enforced a 300 KB minimum file size cutoff to filter out sound effects, notification tones, and UI clicks.
  - Added folder blacklist (`node_modules`, `build`, `out`, `assets`, `WhatsApp`, etc.), 2-level depth caps in Downloads, and `.nomedia` compliance.
  - Automatic pruning of deleted/moved files from SQLite on rescan and real-time filesystem checks in `localTracksStreamProvider`.
  - Guarded playback in `SoftifyAudioHandler` to prevent `local_` files from falling back to online streaming search when missing or unplayable.
  - Declared `READ_MEDIA_AUDIO` and `READ_EXTERNAL_STORAGE` permissions in `AndroidManifest.xml` for Android mobile access.
