# Softify — Application Screenshots

This directory contains the visual screenshot assets for Softify. 

## Screenshot Catalog

| Filename | Description | Screen / Flow |
|---|---|---|
| `home.png` | Personalized Home Screen | Dynamic greeting, quick resume tiles, taste-based recommendations, and trending charts |
| `player.png` | Full-Screen Studio Player | High-resolution artwork, 320 kbps studio indicator, seek bar, and playback controls |
| `lyrics.png` | Synchronized Karaoke Lyrics | Real-time timestamped auto-scrolling lyrics with tap-to-seek functionality |
| `search.png` | Instant Search & Autocomplete | Search debouncing, genre browse cards, and deduplicated studio cuts |
| `library.png` | Your Library & Playlists | Custom playlists, liked songs, and Spotify-imported collections |
| `downloads.png` | Offline Downloads Manager | Active download progress meters, storage usage breakdown, and offline playback |
| `spotify_import.png` | Spotify Playlist Importer | Instant URL extraction, candidate confidence scoring, and 1-tap batch import |

## Guidelines for Screenshots

- **Display Palette**: Pure AMOLED Dark (`#121212` background, `#1DB954` Spotify Green accents, `#FFFFFF` high-contrast typography).
- **Aspect Ratio**: 9:19.5 or 9:20 (Standard modern Android viewport: 1080x2400 or 1440x3200).
- **Status Bar**: Cleaned status bar (full battery, 100% Wi-Fi, 9:41 AM clock).
- **Format**: Lossless `.png` or optimized `.webp`.
